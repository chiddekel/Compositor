## Full release notes and assets

### Compositor 1.4.1 (`v1.4.1`)

- **Published:** 2026-09-29T05:21:06Z
- **Author:** robbietilton
- **Draft / prerelease:** False / False
- **URL:** https://github.com/robbietilton/Compositor/releases/tag/v1.4.1
- **Asset:** `Compositor.dmg` — 6.42 MiB, 521 downloads
  - https://github.com/robbietilton/Compositor/releases/download/v1.4.1/Compositor.dmg

- Resize handles snap to the canvas, other layers and guides, as moving does.
- Values typed or dragged in the Move bar's X, Y, W, H, Scale and rotation fields apply straight away, with no Apply, as one undo step.
- Clone Stamp and Blur keep a scaled-down layer's full detail, so it stays sharp when scaled back up.
- Layer masks work like Photoshop's: with a selection, Add Layer Mask reveals it (Option-click for the opposite), and Option-clicking a mask thumbnail shows the mask on its own.
- Ungroup Layers (⇧⌘G), also in a folder's right-click menu.
- Tabs can be dragged to reorder, and ones that don't fit gather under a menu.
- Holding Command flips Auto Select either way while it's held.
- A brush that can't paint now says why, and Select All then Inverse deselects.
- Scaled layers show their scale in the Layers panel, and Cancel and Apply only appear when an edit is waiting for them.

Thanks to @cheyras for several of these.

### Compositor 1.4 (`v1.4`)

- **Published:** 2026-09-28T19:34:01Z
- **Author:** robbietilton
- **Draft / prerelease:** False / False
- **URL:** https://github.com/robbietilton/Compositor/releases/tag/v1.4
- **Asset:** `Compositor.dmg` — 6.39 MiB, 717 downloads
  - https://github.com/robbietilton/Compositor/releases/download/v1.4/Compositor.dmg

Compositor 1.4 draws the canvas on the GPU.

- Moving, rotating, scaling, panning and zooming are much smoother, and so are painting, gradients, moving selected pixels, Smudge and Liquify, distort, and every adjustment layer.
- A sharper canvas on Retina displays for documents with adjustment layers.
- Photoshop import: Levels gamma, Hue/Saturation settings, and layer masks that came in stretched.
- Hue/Saturation's Saturation now matches Photoshop's.
- Blend modes: Linear Dodge and Photoshop's other modes on clipping stacks and adjustments, and Soft Light in export and Copy Merged, now match the canvas.
- Showing and hiding folders no longer lags in documents with hundreds of layers.
- Noise and Grain stay with the document as you pan, and Grain matches export at any zoom.
- Blur filter previews no longer flicker as you drag.
- A new layer mask no longer shows the layer semi-transparent.
- Shift keeps Cmd-dragged pixels on a straight line, and Cmd-A always selects the canvas.
