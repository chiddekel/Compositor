## Closeout pass (2026-10-09)

The first pass marked every commit Done from themes. A per-file check found what it missed; all fixes are in the
Linux layer (`Compositor/` and `CompositorTests/` stay identical to upstream):

- **Tool combinations** (`Tests/LinuxOverrideTests/ToolCombinationTests.swift`, 13 tests incl. every ordered tool pair).
  On the previous HEAD three failed: Show Transform Controls armed a Free Transform that blocked every other tool
  (the "text + selection + gradient doesn't work" report), a pending gradient made the next brush stroke fail, and a
  refused gradient reported "could not start" instead of upstream's reason. Fixed in `UpstreamEditor.swift`:
  a pending gradient is applied before the next command (as the Mac's run loop does between clicks), tool begins and
  `selectTool` report upstream's `paintRefusal` / alert text, and Show Controls is a display setting again.
- **Overrides re-synced with tip:** `ContentView` (Last Filter without the panel, import alert OK role),
  `KeyboardShortcuts` (Search Commands, Last Filter, Export As, Toggle Fullscreen; Linux help text), `LayerMaskMenu`
  (`layersLookEditable`, `FooterIcon`, no borderless style). `scripts/upstream-override-drift.py --check` now fails the
  gate when a hand override misses an upstream change.
- **Compat fixes found by upstream tests:** `CIContext.render(.RGBA16)` renders from the float graph and
  `CILinearGradient` generates (RawDitherTests crashed); `dlsym` used Darwin's `RTLD_DEFAULT` (-2), which segfaults on
  glibc whenever the Vulkan canvas is probed; Color Range sampling traps on a non-finite point (generator fix in
  `gen-color-range.py`).
- **Gates:** `check-upstream-clean.sh` also runs `build-brush-shader.py --check`, the override drift check and
  `upstream-ledger-rows.py --check`.
