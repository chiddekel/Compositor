## What the Linux layer needed

- **`.scrollIndicators(.never)`** (`7311d69`): compat SwiftUI has the `never` visibility, and the Qt renderer hides a
  scroll area's bars for it as for `.hidden`. Linux has no "always show scrollers" setting to override, so the two
  behave the same. `TypeControls` is generated from tip and takes the change by regenerating.
- **CI** (`518d0bf`, `3081719`): GitHub Actions and Xcode UI screenshot tests. Mac only; `scripts/ci-tests.sh` is
  upstream's Xcode test driver.

- **Folders** (`b2a0c45`): the two new import tests run unchanged. The native preview covers mixed file/folder selection, duplicate/removal handling and name-ordered import without hidden or nested files. Actual desktop portal directory grants remain a separate verification item.
- **Narrow Layers panel** (`0a5c8d9`): the Qt dock resizes within the upstream 222–352-point bounds and feeds its content width into the unchanged LayersPanel body. Saved old widths clamp before rendering; invalid offers leave the width unchanged. Native custom pop-up sizing supplies its minimum width. The preview verifies both endpoints, control containment and a pointer-driven splitter drag without pixel or Undo changes. Its decorative stack border no longer consumes the minimum content width. Real desktop layout and Mac screenshot comparison remain separate checks.

- **Blur** (`9a0ad3e`): compat Core Image implements unpremultiplication and bounded alpha-one operations used by upstream’s transparency-preserving blur. Original tests and the native transparent-color fixture cover exact alpha, geometry and Undo/Redo.
- **RAW** (`248d4d4`): capability/default queries and extended LibRaw develop callbacks carry noise/highlight controls into draft and full output. Immutable sensor dimensions/color/CFA keep resizing and reset stable. Generated DNGs exercise supported and unsupported controls and actual pixel changes; the upstream sheet is hosted through Qt. The compat Group-modifier fix preserves all five sliders, both toggles and all three action buttons. Lens correction stays disabled because this backend has no lens-profile engine. Both dependency build paths apply the one-line LibRaw 0.22.2 OpenMP wavelet allocation-size fix.
- **PatchMatch** (`23913d3`, `39d1257`): the protected C source is consumed unchanged by SwiftPM and checked CMake wrappers. Native checks verify seed determinism, unchanged pixels outside the hole, no-source refusal, ten allocation failures and both stride guards. Checked adjustment wrappers are generated from the current upstream header so CMake signatures cannot silently lag behind SwiftPM.
