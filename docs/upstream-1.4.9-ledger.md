## What the Linux layer needed

- **Libdispatch in the C kernels:** tip `AdjustPixels.c` splits work with `dispatch_apply` blocks; `CompositorKernels`
  now builds with `-fblocks` and links the toolchain's libdispatch (`Package.swift`), so it runs in parallel as on macOS.
- **`NSData.decompressed(using: .lzma)`:** added to `FoundationCompat` over liblzma (`Sources/CLZMA`); the Camera Raw
  tables are an XZ stream.
- **`CameraRawTables.bin` via `Bundle.main`:** installed beside the binary (Flatpak manifest, `run-compositor.sh`;
  tests: see `docs/upstream-test-baseline.md`).
- **Sparkle:** the compat updater gains `checkForUpdates()`; tip `UpdateDriver.swift` (an AppKit update alert) is
  excluded, Linux updates through Flatpak.
- **Middle button:** compat `CGEvent` mouse types/buttons and `NSEvent(cgEvent:)` coordinates (for upstream's
  `MiddleButtonTests`); the Qt canvas forwards middle-button press/drag/release to upstream's `CanvasView`, which pans,
  or with Ctrl (⌘) / Meta (⌃) zooms.
- **WebP drop:** compat `NSItemProvider.registerDataRepresentation`.
- **Tabs:** `ProjectTabs` override takes the closable-tab change (and is now drift-checked).
