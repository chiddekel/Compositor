Install once. Keep up to date.

Open the Flatpak install file in your software center, or use the commands below. Set up Flatpak first if your distribution needs it.

flatpak install --user @SITE_URL@/com.compositor.Client.flatpakref
flatpak run com.compositor.Client

In Compositor, choose Check for Updates… from the application menu, then Check and Update. You can also use your software center. After an update, save your work and reopen the app.

Terminal updates and repository details 
flatpak update com.compositor.Client
